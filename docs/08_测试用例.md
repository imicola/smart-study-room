## 1 说明

### 1.1 编写目的

本文件给出"智能共享自习室预约系统"的全部测试用例，逐条对应《测试计划》SSR-TP-001 确定的测试范围，作为测试执行与回归的检查单，其结果见《系统测试报告》SSR-TEST-001。

### 1.2 用例编号规则

| 前缀 | 含义 | 对应脚本/代码 |
| --- | --- | --- |
| TC-A | 自动分配算法单元测试 | `backend/internal/service/allocation_test.go` |
| TC-V | 预约时段校验单元测试 | `backend/internal/service/reservation_test.go` |
| TC-M | 限流中间件单元测试 | `backend/internal/middleware/ratelimit_test.go` |
| TC-S | 分布式锁单元测试 | `backend/internal/pkg/redissync/lock_test.go` |
| TC-C | 旁路缓存单元测试 | `backend/internal/pkg/rediscache/cache_test.go` |
| TC-U | 认证与令牌注销单元测试 | `backend/internal/service/auth_redis_test.go`、`handler/auth_test.go` |
| TC-AI | AI 客户端单元测试 | `backend/internal/service/ai_client_test.go` |
| TC-A0x | 配置解析单元测试 | `backend/internal/config/config_test.go` |
| TC-API | 接口端到端集成测试 | `scripts/test_api_e2e.py` |
| TC-CC | 并发抢座测试 | `scripts/test_concurrency.py` |
| TC-B | 前端构建验证 | `npm run build` |

### 1.3 用例要素

每条用例包含：编号、名称、优先级、前置条件、测试步骤/输入、预期结果。

**优先级定义**：P0 = 阻断级（不通过则不可交付）；P1 = 重要；P2 = 一般。

### 2.1 自动分配算法（TC-A）

| 编号 | 用例名称 | 优先级 | 输入 | 预期结果 |

| TC-A01 | 偏好加权评分（区域+30、电源+25、靠窗+15） | P0 | 同时满足区域/电源/靠窗偏好的候选座位 | 最优候选得分落于 [70, 71)；推荐理由包含三项标签 |

## 4 并发与性能测试用例（TC-CC）

**执行脚本**：`scripts/test_concurrency.py`

| 编号 | 用例名称 | 优先级 | 场景 | 预期结果 |
| --- | --- | --- | --- | --- |
| TC-CC-01 | 20 并发抢同一座位防超卖 | P0 | 20 个独立学生 JWT 瞬时抢占座位 12（2026-09-28 14:00—16:00） | 成功数 **严格 = 1**；冲突数 **严格 = 19**；5xx = 0 |

| 指标 | 要求 |
| --- | --- |
| 成功预约数 | 严格等于 1 |
| 冲突阻断数 | 严格等于 19 |
| 服务异常数（5xx） | 0 |
| P95 响应时间 | < 500 ms |
| 20 并发总耗时 | < 1000 ms |
